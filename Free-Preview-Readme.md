# Free account and Kids Library preview

This update adds no paid service and does not create subscriptions.

Upload all ZIP contents to the existing ward-bulletin site, replacing matching files. Keep existing vendor files and artwork.

1. Open Account & plans in the editor header.
2. Enter optional account details and select a plan and billing period to preview.
3. Save preview settings. Kids or Bundle makes the Kids Program Library link appear beside the editor tabs.
4. In Kids Program Library, expand Add a program to your local library and upload a PDF with its title, date, and optional topics.
5. Search by title/topic/holiday, filter by month/activity, download, or remove local programs.

Account preview settings and library files are saved only in the current browser. Keep original PDFs. Real authentication, invitations, cloud sharing, payments, and subscription enforcement are not connected.

No password or credit card information is requested. Plan selections here are freely editable demonstrations, not paid access checks.

Verified: approved monthly/annual prices, optional Library tab, plan save in a browser, searchable PDF uploads, persistence across reload, download/removal handlers, invalid PDF rejection, and existing bulletin/digital/storage regression checks.
